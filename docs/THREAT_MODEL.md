# 下载与发布服务威胁模型

## 保护对象

- LYNX 和其他产品发布资产及其不可变历史。
- 管理员身份、会话和发布审批记录。
- 更新清单、稳定渠道指针、摘要和公开验签密钥。
- 服务器文件系统中不应公开的暂存、回收站和运行配置。

## 主要威胁

| 威胁 | 必须实施的控制 |
| --- | --- |
| 弱口令和撞库 | 无默认口令、bcrypt、登录限速、可扩展二次认证 |
| 会话窃取 | 随机令牌只存哈希、Secure/HttpOnly/SameSite Cookie、到期撤销 |
| 跨站请求伪造 | 每会话 CSRF 令牌、Origin 校验、状态变更只接受非 GET 方法 |
| 路径穿越或符号链接越界 | 规范化相对路径、拒绝受管路径中的符号链接、临时文件同盘原子移动 |
| 上传半成品被下载 | 上传只进入非公开暂存目录，校验完成后原子发布 |
| 发布资产被替换 | `/Tools/<product>/releases/<channel>/<version>` 版本化不可变路径、SHA-256、签名、公钥校验、审计 |
| SCP/CI 绕过后台 | forced-command 白名单只允许无副作用协议探针、`.part-*`/SCP/原子改名/dlctl；清单外文件拒绝导入 |
| 删除事故 | 回收站、二次确认、审计、单独永久清理策略 |
| 服务进程扩大影响 | 非 root 服务用户、状态目录最小权限、Nginx 与管理 API 分离 |
| 镜像被篡改或回放 | 两源同摘要同签名、客户端版本单调、旧清单不得触发降级 |

## 明确不做

- 下载服务器不生成发布签名，也不保存签名私钥。
- 更新客户端不执行服务端提供的任意脚本、路径或命令。
- 上传完成不等于发布完成；任何入口都不能默认自动进入 stable。
