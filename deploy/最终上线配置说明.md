# 当前生产配置

`dl.100ask.net` 只运行 Go 版 `dladmin-go`：

```text
/home1/dladmin-code/current       源码与可执行文件
/home1/dlfile                     原有下载文件，不得覆盖
/home1/dlfile-state               SQLite、incoming、staged、trash、日志
127.0.0.1:5001                    Go HTTP 服务
```

部署时使用：

- `deploy/systemd/dladmin-go.service`
- `deploy/nginx/dl.100ask.net.baota.conf`
- `deploy/ssh/dl-release-command`

源码提交只做 Go 测试和静态构建，不自动登录服务器、重启服务或处理下载文件。
完整步骤见 [`../DEPLOYMENT.md`](../DEPLOYMENT.md)。
